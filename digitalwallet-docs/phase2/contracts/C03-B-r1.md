## 2. Compatibility contract

| Surface | Contract after C03-B |
|---|---|
| Identity API | Immutable `RegisterUserInput`, `UserView`, `LoginInput`, `AuthResult`; `IdentityRegistrationApi.createUser` and `IdentityAuthApi.login` |
| Onboarding API | `RegisterAccountApi.register` composes Identity and Wallet inside one `REQUIRED` transaction |
| Wallet API | Immutable `WalletView(id, userId, walletNumber, balance, status, version, createdAt, updatedAt)`; `WalletCreationApi.createInitialWallet` is invoked by Onboarding only |
| HTTP | Preserve `POST /api/v1/auth/register` = 201 and `POST /api/v1/auth/login` = 200, response envelope and Bearer JWT fields |
| Schema | No schema or Flyway migration change; `baselineOnMigrate=false` remains unchanged |
| Transaction | Identity user write and Wallet initial write are `MANDATORY`; wallet failure rolls back the new user |
| Time | Public identity and wallet timestamps are `Instant`; legacy MySQL `DATETIME` is interpreted and written as UTC (`ZoneOffset.UTC`) |

The Identity domain contains no Spring or JPA dependency. Persistence and HTTP/security adapters are outside the domain. Module-to-module references must target `.api` packages and the module graph must remain acyclic.

## 3. Narrow transitional exception

C03-B retains exactly one production bridge until C03-A migrates Wallet persistence:

- source: `wallet.adapter.legacy.LegacyWalletCreationBridge`
- allowed legacy targets: `application.port.out.SaveWalletPort`, `domain.model.Wallet`, and the generated nested `Wallet$WalletBuilder`
- purpose: preserve the Phase 1 initial-wallet write while publishing `WalletCreationApi`
- removal owner/ticket: A in C03-A

No wildcard or package-wide exception is allowed. `ModuleArchitectureTest` fails if any other named-module class imports a legacy type.

One legacy caller remains while the shared web error handler has not yet moved into a named module: `adapter.in.web.handler.GlobalExceptionHandler` may import only the public Identity errors `DuplicateUserException` and `InvalidCredentialsException`. It may not import Identity application/domain/adapter types or any other named-module API. The architecture policy lists the source and two target classes exactly.
