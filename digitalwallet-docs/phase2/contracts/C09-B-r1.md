## 2. Safe independent implementation

| Requirement | Result |
|---|---|
| Production missing JWT secret fails startup | Base `application.properties` requires `${APP_JWT_SECRET}` without fallback |
| Blank/weak secret fails startup | Both JWT beans apply a shared minimum policy: non-blank, at least 32 UTF-8 bytes |
| Test/dev keys are separate | Dev-only fallback lives only in `application-dev.properties`; the Gradle `test` process injects a distinct test-only environment value |
| No deployment credential in source/CI | `.env.example` contains an empty required variable; CI retains its test-only environment value |
| JWT behavior compatibility | Claims, signing algorithm selection, Bearer type and expiry behavior are unchanged; existing JWT round-trip passes |

The key value is never logged or included in an exception. Deployment must supply unique random signing material and must not enable the dev profile.
